# Grid-Search-of-Optimal-Hyper-Parameters
This repo contains kaggle link to grid search and some of my contributions to DFU Classification task .

## Optimizing Deep Learning Architectures for Ulcer Detection

<strong>Key Contributions:</strong> Conducted an exhaustive grid search for hyperparameter optimization and produced detailed architectural visualizations at every structural level.

<strong>Pros:</strong> Significantly improved model robustness through the identification of optimal hyperparameter configurations.

<strong>Cons:</strong> Architectural visualization revealed a latent dimensionality mismatch at a specific bottleneck, identifying a critical area for structural refinement.
